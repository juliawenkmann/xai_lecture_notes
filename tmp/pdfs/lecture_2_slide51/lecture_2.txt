                             Decision tree: quick recap


I What is a decision tree?
    I tree with root = X and leaves = cells
    I iterative binary decisions based on feature values
    I node of the tree: “is feature j smaller than x ?”
    I if yes, go left, if not, go right
    I Can also be visualized as partition of the input space X
    I each query point falls into a cell, constant prediction on each cell
I two different modes:
    I classification æ class label æ majority vote
    I regression æ real number æ empirical average
